1. Eddy Viscosity Closure

The model keeps the realizable k-epsilon structure and computes turbulent viscosity from a variable realizable coefficient.

Turbulent Viscosity

νt = rCμ k2 / ε

Realizable Coefficient

rCμ = 1 / (A0 + As Us k / ε)

W = 2√2 ((S:S):S) / (|S| S2 + small)

φs = (1/3) cos-1(clamp(√6 W, -1, 1))

As = √6 cos(φs),  Us = √(S2/2 + |skew(∇U)|2)

  • S = dev(symm(gradU)) in the realizable coefficient
  • S2 = 2 |dev(symm(gradU))|^2 in the solver step
  • ε is bounded by 0.09 k^2 / (nutMaxCoeff nu)
  • omegaLike = ε / (0.09 max(k, kSmall))

2. Implemented Transport Equations

These are the equations actually assembled in realizableKE_BCS2.C.

Epsilon Equation

∂(αρε)/∂t + ∇·(αρUε) - ∇·(αρDε,eff∇ε)

= C1αρ|S|ε - C2αρε2 / (k + √(νε)) - αρ C1 B (Gb / (k + ksmall)) ε + Sε

k Equation

∂(αρk)/∂t + ∇·(αρUk) - ∇·(αρDk,eff∇k)

= αρ G fr,eff - αρ(Gb / (k + ksmall)) k - (2/3)αρk ∇·U - αρε + Sk

Diffusion and Production Terms

Dk,eff = ν + νt / σk,  Dε,eff = ν + νt / σε

G = νt (∇U : dev(2 symm(∇U)))

η = |S| k / ε,  C1 = max(η / (5 + η), 0.43)

3. BCS2 Correction Terms

The helper computes swirl gating, curvature amplification, and an optional buoyancy term.

Swirl Sensor

Slocal = |uθ| / (|Uaxial| + εswirl)

Fswirl = clamp((Slocal - S0) / (S1 - S0), 0, 1)

Curvature Correction

r* = |S| / max(|Ω|, ωsmall)

D2 = max(|S|2, 0.09 ωlike2)

r̃ = (2 symm(ΩS) : DS/Dt) / max(|Ω| D3, small)

frot = (1 + cr1) (2r* / (1 + r*)) (1 - cr3 tan-1(cr2 r̃)) - cr1

f̃r = clamp(frot, 0, fr,max)

fr = max(0, 1 + ccurv(f̃r - 1))

fr,eff = 1 + Fswirl(fr - 1)

Optional Buoyancy Term

Gb = Cg νt (g · ∇ρ) / max(ρ, ρsmall)

B = tanh(|v| / u),  v = ĝ · U,  u = |U - ĝv| + usmall
